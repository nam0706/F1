# F1 Final Dataset Pipeline

This project builds a clean Formula 1 lap-level dataset for a **Live before lap N** prediction setting.

The course scope stops at data collection, preprocessing, feature engineering, EDA, and an app demo. It does not train a model.

## Project Scope

The final dataset is designed for this prediction moment:

```text
Live before lap N
```

For a row at lap `N`, model-safe features must only use information available before lap `N` starts. In practice, this means:

- previous-lap telemetry/location features use `tele_prev_*` and `loc_prev_*`
- event counters use `*_before_lap` or `*_so_far`
- outcome columns such as `final_position` and `target_*` are labels or audit columns, not input features

## Main Pipeline

The pipeline is controlled by:

```text
configs/pipeline_config.yaml
```

For grading/rerunning, the default config skips crawling because it is slow and depends on OpenF1/FastF1 network availability:

```yaml
execution:
  steps_to_run:
    - clean
    - base
    - feature
```

Run from the project root:

```powershell
python run_e2e_pipeline.py
```

This rebuilds derived artifacts from the existing files under `data/raw/`.

## Pipeline Outputs

### Cleaned Data

Generated by `src/clean_data.py`:

```text
data/cleaned/*.csv
data/cleaned/*.parquet
reports/data_quality/cleaning_summary.csv
reports/data_quality/cleaning_summary.md
```

### Intermediate Base Dataset

Generated by `src/build_base_dataset.py`:

```text
data/processed/driver_session_base.csv
data/processed/driver_session_base.parquet
reports/data_quality/base_dataset_report.md
```

This is a driver-session level artifact with grain:

```text
session_key + driver_number
```

### Final Dataset

Generated by `src/feature_engineering.py`:

```text
data/processed/master_dataset.parquet
data/processed/master_dataset.csv
data/metadata/feature_engineering_metadata.json
reports/data_quality/master_dataset_audit.csv
reports/data_quality/master_dataset_audit.md
```

The final dataset grain is:

```text
session_key + driver_number + lap_number
```

The metadata file records the prediction contract, model-safe feature columns, label columns, learned tyre cliff values, row count, and column count.

## Final Dataset Labels

The final dataset includes labels/outcome columns such as:

```text
final_position
target_win
target_podium
target_top10
```

These columns are useful for analysis and future supervised learning, but they must not be used as input features for the live-before-lap prediction setting.

## Data Sources

The project uses:

- OpenF1 API data for session, lap, weather, pit, race control, interval, result, and related endpoints
- FastF1 telemetry/location data for car and location signals

The current grading config does not crawl again. To enable crawling, add `crawl` back into `execution.steps_to_run` in `configs/pipeline_config.yaml`.

## Notebooks

Important notebooks:

```text
notebook/eda_raw_profiling.ipynb
notebook/eda_feature_engineering_deep.ipynb
notebook/eda_model_ready_live_before_lap.ipynb
```

Recommended reading order:

1. `eda_raw_profiling.ipynb`: raw endpoint profiling, schema/grain risks, leakage risks
2. `eda_feature_engineering_deep.ipynb`: deeper EDA and feature usefulness analysis
3. `eda_model_ready_live_before_lap.ipynb`: final dataset audit for the live-before-lap contract

## Streamlit App

The app is a dataset explorer and replay demo, not a prediction app.

Run:

```powershell
streamlit run apps/final_dataset_explorer/streamlit_app.py
```

The app reads:

```text
data/processed/master_dataset.parquet
data/processed/master_dataset.csv
data/metadata/feature_engineering_metadata.json
reports/data_quality/master_dataset_audit.csv
reports/data_quality/cleaning_summary.csv
data/cleaned/location.parquet
```

Main app tabs:

- overview of final dataset size, grain, and contract
- quality/audit summaries
- EDA charts from the final dataset
- live contract and safe feature groups
- race replay from cleaned location data

## Repository Layout

```text
apps/final_dataset_explorer/   Streamlit final dataset explorer
configs/                       Pipeline configuration
data/raw/                      Existing raw data used for rerun
data/cleaned/                  Cleaned endpoint artifacts

reports/data_quality/          Pipeline-generated summaries and audits

```

## Notes For Review

- The final dataset is lap-level and leakage-aware for `Live before lap N`.
- Crawling is intentionally disabled in the default config to make reruns faster and more reproducible for grading.
